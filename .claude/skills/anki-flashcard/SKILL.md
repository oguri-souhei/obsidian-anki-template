# Anki フラッシュカード作成

`Study/` 配下のノートを読み、`Flashcards/` 配下にカードを書き足す。

## 前提

このvaultは Obsidian の flashcards プラグイン（flashcards-obsidian v2）を使う。Anki への同期はプラグインが行う。

- カードは `#card` 構文で書く。
- ブロックID（`^q-xxxx`）と frontmatter の `flashcards:` は、**プラグインが同期時に自動で付ける。絶対に書かない。**
- プラグインは空行で区切られたかたまり単位でカードを読む。カード同士は必ず空行1つで区切る。

## 手順

### 1. 対象ノートを抽出する

```bash
.claude/skills/anki-flashcard/scripts/find-targets.sh
```

スクリプトが以下の条件で絞り込む。手で探さない。

- frontmatter の `tags` に `Anki` が含まれる
- `flashcard_created` が未チェック（キーなし / 空 / `false`）

出力が空なら「対象なし」と伝えて終了する。

### 2. ノートを読んで理解する

抽出された各ノートを読む。何を覚えるためのノートなのかを掴んでから、カードの問いを決める。

- 覚える単位が複数あれば、その数だけカードを作る（見出しごと、概念ごと、語源など）。
- 単位が1つなら1枚でよい。枚数を水増ししない。
- 問いは、答えが一意に決まる形にする。「〜とは？」「〜の目的は？」など。

### 3. Flashcards 配下に書く

書き込み先は `Flashcards/{カテゴリ}.md`。カテゴリは `Study/` 直下のフォルダ名。

- `Study/応用情報技術者試験/メモリインターリーブ.md` → `Flashcards/応用情報技術者試験.md`

ファイルが無ければ新規作成する（frontmatter は付けない。プラグインが付ける）。あればファイル末尾に追記する。**既存のカードと frontmatter は書き換えない。**

書式:

```
{問い} #card
{答え}
{ノートにある画像があれば ![[画像ファイル名]]}
[[{元ノートのファイル名（拡張子なし）}]]
```

実例（`Flashcards/応用情報技術者試験.md`）:

```
メモリインターリーブとは？ #card
**メモリインターリーブ**（memory interleaving）は、物理上はひとつの主記憶領域を、同時アクセス可能な複数の論理的な領域（**バンク**）に分け、メモリアクセスの高速化を図る手法。
![[Pasted image 20260907195403.png]]
[[メモリインターリーブ]]
```

書式のルール:

- 答えは元ノートの表現をそのまま使う。要約して情報を落とさない。太字などの装飾も残す。
- 画像は元ノートの `![[...]]` をそのままコピーする。**ファイルはコピーしない。** Obsidian はvault全体からファイル名で解決するので、`Study/` 配下にある画像もそのまま表示され、Anki にも同期される。
- 画像は、その画像が説明している内容のカードにだけ貼る。関係ないカードには貼らない。
- 最終行は必ず元ノートへのリンク `[[ノート名]]` にする。
- カード内に空行を入れない。空行を入れるとそこでカードが切れる。
- カードとカードの間は空行1つで区切る。

### 4. flashcard_created にチェックを入れる

カードを書き終えた元ノートの frontmatter を更新する。

- `flashcard_created:` がある → `flashcard_created: true`
- キーが無い → frontmatter 内に `flashcard_created: true` を追加する

このプロパティは Obsidian 上で checkbox 型なので、値は必ず `true`。

## 確認

書き終えたら、生成したファイルを読み直して確認する。

- `^q-` で始まるブロックIDを書いていないこと
- カードとカードの間に空行があり、カード内には空行が無いこと
- `[[...]]` のノート名が実在するノートのファイル名と一致していること
- 画像の `![[...]]` がvault内に実在するファイル名であること
- `find-targets.sh` を再実行して、処理したノートが出力されなくなっていること
