## 使い方
例) 応用情報の勉強

1. 学んだ内容を `Study/応用情報技術者試験`配下にメモ
	1. その時に `#Anki` タグを付与すること
2. このリポジトリで `claude` を起動
3. `/anki-flashcard` を実行する。（ `Flashcards/`配下にフラッシュカードの元を作成する）![[Pasted image 20260907202505.png]]
4. コマンドパレット ( `cmd + P` ) から `Flashcards: Update Anki from vault`を実行することで、Ankiにフラッシュカードが同期される![[Pasted image 20260907202445.png]]
